# FD MATH FORMS 📚⚡

Plataforma educativa con formularios, tablas y guías de estudio de matemáticas universitarias (Cálculo Diferencial, Integral, Geometría Analítica) listas para descargar en PDF.

🌐 **Sitio Web Oficial:** [https://fdmathforms.github.io/](https://fdmathforms-17.github.io/fdmathforms/) 

## 🚀 Contenido Disponible
- Derivadas Base
- Guía Completa de Funciones
- Límites
- Guía de Continuidad de Funciones
- Estudio de Curvas
- Optimización y Rapidez de Variación
